# Go 语言资源汇总

## Go 语言学习指南

- [GitHub - coderit666/GoGuide](https://github.com/coderit666/GoGuide)：一份涵盖大部分 Golang 程序员所需要掌握的核心知识，拥有 Go 语言教程、Go 开源书籍、Go 语言入门教程、Go 语言学习路线。零基础学习 Go 语言、Go 编程，首选 GoGuide。
- [Go 语言之旅](https://tour.go-zh.org/welcome/1)：Go 官方推出的交互式学习教程，涵盖 Go 语言基础语法、数据结构、并发编程等内容。
- [Golang 开发规范](https://goguide.ryansu.tech/guide/standard/1-golang.html)：详细介绍 Go 语言的开发规范，包括代码格式、命名规则、错误处理等。
- [网络编程 · Go 语言中文文档](https://www.topgoer.com/%E7%BD%91%E7%BB%9C%E7%BC%96%E7%A8%8B/)：Go 语言网络编程相关文档，涵盖互联网协议、Socket 编程、HTTP 编程、WebSocket 编程等内容。

## Go 语言编程实战

- [Go 语言 github.com/gorilla/websocket 框架 websocket 协议通信实战](https://blog.csdn.net/hsy12342611/article/details/131698876)：基于 github.com/gorilla/websocket 框架的 WebSocket 通信实战教程，包括服务端、Go 客户端和网页客户端的实现。

## Go 语言资源

- [go 官方国内镜像](https://golang.google.cn/)：Go 官方网站，提供 Go 语言下载、文档、教程等资源。
- [go 中文学习下载](https://studygolang.com/dl)：Go 语言中文网，提供 Go 语言的下载、教程、文档等资源。
- [Golang 标准库文档](https://studygolang.com/pkgdoc)：Go 语言标准库文档，详细介绍了 Go 语言标准库的各个包及其使用方法。

## Go 语言进阶

- [Go 与 C 的桥梁：cgo 入门，剖析与实践](https://zhuanlan.zhihu.com/p/349197066)：介绍 Go 语言与 C 语言混合编程的 cgo 技术，涵盖入门到实践的内容。
- [全面总结： Golang 调用 C/C++，例子式教程](https://www.cnblogs.com/linguanh/p/8323487.html)：详细总结 Go 语言调用 C/C++ 的方法和示例。
